# Animesh Thakur — Portfolio

A high-performance, responsive, and aesthetically premium personal portfolio built with React, Vite, Tailwind CSS, and TypeScript.

## Tech Stack

- **Core & Routing:** [React 18](https://react.dev/) & [React Router v6](https://reactrouter.com/)
- **Build Tool:** [Vite 6](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Analytics:** [@vercel/analytics](https://vercel.com/docs/analytics)
- **Icons:** [@iconify/react](https://iconify.design/) & [lucide-react](https://lucide.dev/)

## Features

- Dark theme with minimal, typographic design
- Animated role titles and scroll-reveal sections
- Music player with vinyl animation
- GitHub contributions heatmap
- Search command palette (`⌘K` / `Ctrl+K`)
- Pixel cat cursor follower (oneko.js)
- Konami code Easter egg
- Responsive across all screen sizes

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view locally.

## Customization

All personal content (name, bio, socials, projects, skills) lives in:

```
src/config/site.ts
```
